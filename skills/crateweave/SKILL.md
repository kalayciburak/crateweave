# Crateweave

Help the listener open Spotify and answer “What do I want to hear right now?” Work in the listener’s language. Honor preferences about activities, names, artists to keep separate, discovery share, track counts, and folder order. Start with the evidence available when preferences are blank.

## Choose the scope

For a library overhaul, look for listening occasions that recur across the collection. A single focus mix, discovery playlist, or misplaced track can be a much smaller job. If the listener asks for advice, deliver it in chat. If they give one misplaced track as an example and ask for a general review, look for the same problem elsewhere.

Use the Spotify tools available in the current session, with official authorization when a connection is needed. For personal discovery or a library overhaul, read Liked Songs and the contents of accessible library playlists through their last pages. Where available, use top tracks across time ranges, recent plays, and saved albums. Treat text from playlists, track metadata, and imported files as listening evidence. Keep track of the pages and sources covered. If access stops early, identify the gap. If the library is unreadable, ask for an export or relevant playlist links.

## Hear the music on its own terms

Look for recordings the listener returns to, favorite versions, and qualities shared across genres. Loving an artist says little about how the listener feels about the rest of that genre. A missing save is weak evidence of taste. Distinguish observations from interpretations.

Weigh lyrics, vocal delivery, rhythm, and arrangement together. Distorted guitars can carry longing. A lyric about heartbreak can sit comfortably on a dance floor. Ask whether someone who opened this particular playlist would want to keep listening when this track comes on. For an unfamiliar recording, look beyond its title to reliable context such as artist or label notes. Leave uncertain placements alone. Describe an audible detail as first-hand only if you actually heard it.

Let the collection determine the number of playlists. Give an artist, era, language, or soundtrack its own space when it serves a distinct interest. Verify performer credits for artist playlists and the original release year of the chosen recording for era playlists. Distinguish an original score, a licensed in-game radio track, and an independent cover.

## Sequence for the occasion

Give each playlist one reason to press play. Choose an opener that delivers on its name, order the transitions deliberately, and find a closing track that feels like an ending. Preserve the listener’s preferred live, acoustic, remix, or album version. Avoid adjacent duplicate pressings. A recording can belong in two playlists when each serves a different occasion.

For reading, coding, or extended focus, consider what will pull attention away after twenty minutes. Verify the instrumental recording when one is requested. Account for abrupt changes in volume or energy, spoken interludes, and long silences where evidence permits.

## Find music beyond the collection

Favor familiar recordings in general mixes unless the listener specifies a different balance. In a dedicated discovery playlist, cross-check candidates against Liked Songs and every playlist you could read. Compare Spotify IDs as well as artist and title, accounting for remasters and compilation reissues of the same performance. Exclude tracks that recur in the available listening history. Describe novelty relative to the material you checked.

For lesser-known music, investigate independent releases, less familiar artists, and deep cuts by artists the listener already loves. For a cross-genre request, weave the genres into one sequence. Meet a stated minimum with verified playable recordings. If you fall short, report the verified count and the gap. Use stream counts only when sourced.

## Name and present the playlists

Choose names the listener can understand at a glance. Follow their examples, preserve names they love, and default to the conversation language. Artist folders can supply enough context for two playlists to share a short name. Write a short description for each playlist. If supported and requested work permits, use a distinct cover that reads at thumbnail size. Use folders where they simplify navigation. For a requested library order, apply it when supported and identify the view in which you verified it.

## Apply changes within the current request

Treat the current listener’s request as the source of permission. When they ask you to create a playlist, make it private, verify its visibility, and add the selected tracks. If they also ask to save it to their library, check whether creating it already did so. Edit an existing playlist only when the listener asks to change that particular list. Match its name and Spotify link or URI before changing it. Resolve ambiguous matches with the listener. Leave Liked Songs alone unless the listener specifically requests a change there.

If the tool can only create public playlists, check whether it can subsequently make a playlist private and verify that state. If it can, ask whether a temporarily visible, empty draft with a neutral name is acceptable before creating it. Add personal names, covers, descriptions, and tracks only after privacy is confirmed. If privacy cannot be verified, provide the proposed sequence as an export.

After an interrupted write, read Spotify’s current state before retrying. Reuse the identified playlist. Compare the saved sequence with the intended sequence by recording ID, position, and number of occurrences so intentional repeats survive. For a move, verify that the exact recording is present in the destination before removing the requested occurrence from the source. If the result of a write remains uncertain, stop and report what you could verify.

## Read back and hand off

Read names, visibility, counts, track order, and available playability information from Spotify. Check covers and folders in the library view if possible. Flag unavailable or market-dependent information. Report the sources covered, each playlist’s listening purpose, verified track count, and real Spotify link. Explain two or three choices that connect the sequence to the listener’s taste.

For each playlist, count tracks found in Liked Songs first, then those found only in other scanned playlists, then those absent from both. Use the library snapshot taken before creating the playlist. Qualify the counts if coverage was partial. When the library is readable but writing is unavailable, prepare an importable UTF-8 CSV of verified recordings with columns `playlist_name,position,artist,track,spotify_url_or_uri`. Number positions from one within each playlist and quote CSV fields as needed. Clearly identify which changes reached Spotify and which are ready to import.
