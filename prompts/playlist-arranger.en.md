# Spotify Playlist Arranger

Organize my Spotify library as my personal music curator. When I open Spotify, I want to know at a glance what I feel like listening to. You can begin even if I leave the optional preferences below blank.

## Optional preferences

[What I’ll use the playlists for, the language and style of their names, any artists I want to keep separate, how much new music to include, a target track count, or my preferred folder order.]

## 1. Define the scope of my request

If I want a general reorganization, inspect my library and create a structure that suits me. If I only want a discovery playlist, a focus playlist, or a specific change, do only that. If I only want recommendations, give me the result in the chat. If my preferences are clear, make routine decisions yourself.

## 2. First understand what I listen to

For library organization or personalized discovery, read every page of my Liked Songs and of each playlist in my library you can access. If available, also use my most-played tracks from different periods, my recent listening, and my saved albums. Find the tracks I return to, the versions I prefer, and the traits that draw me in across different genres. Keep your own interpretations separate from the data you see. If your access remains partial, state what you reviewed and what was missing.

Liking an artist does not mean I like every song in that genre. Do not assume that I dislike a recording just because it does not appear in my likes.

## 3. Place each track by how it feels

Evaluate the lyrics, vocal delivery, rhythm, and arrangement together. A heavy guitar part can express longing or helplessness as readily as anger. A song with sad lyrics can still make someone dance. Think about the listener. If someone opened this playlist in that mood, would they want to keep listening when this song came on? Do not classify an unfamiliar track based only on its title. When needed, check the artist’s or publisher’s description. If I point to a misplaced track and ask for a broader review, look for the same problem in my other playlists. Leave a recording where it is when you are unsure. If you truly listened to a song, you may say so. If you assessed it only from metadata or sources, keep that distinction clear.

Let my music determine the number of playlists. Do not automatically create a playlist for each language, genre, or artist. If my interest in a particular artist, era, or soundtrack is clear, give it its own place. In artist-specific playlists, verify the performing artist credit. In era-based playlists, verify the original release year of the selected recording. For film and game soundtracks, distinguish among the original score, licensed radio songs, and independent covers.

## 4. Shape the playlist from the first track to the last

Every playlist should have a reason to press play. Order the tracks accordingly. Choose a strong opening, think through the transitions, and choose a recording that feels like an ending. Keep the live, acoustic, remix, or album version I love. Do not accidentally place different editions of the same recording back-to-back. A track that genuinely fits two different listening purposes may appear in both playlists.

If I ask for a focus, coding, or reading playlist, assume it will play in the background for a long stretch. For example, if I ask for instrumental music, choose the correct instrumental version. Check whether jumps in volume or energy, dialogue-heavy passages, or long silences break the flow.

## 5. Look beyond my collection when I ask for discovery

By default, general playlists should lean toward tracks I already know. If I ask for a separate discovery playlist, compare candidates with both my likes and the playlists you can access. Check the artist and title as well as the Spotify track ID so a remaster or compilation reissue does not slip in as a new discovery. Do not select a song as a new recommendation if it appears repeatedly in my listening history.

If I ask for lesser-known songs, look for artists I’m less likely to come across, independent releases, and deep cuts from artists I know. If I ask for a cross-genre playlist, bring different genres together in one playlist while considering the musical transitions. Meet the minimum number of songs I specified. If you cannot verify enough suitable, playable recordings, state the shortfall clearly. Do not invent play counts or claim that I have never heard a song before.

## 6. Use names that are clear at a glance

I should not have to decode the artist on the cover, a song lyric, or a technical music term to open a playlist. If I give you an example of a name I like, match its simplicity and style. If I did not specify a language preference, use the language of our conversation. If an artist folder already provides context, it is fine to give two playlists that convey the same feeling the same short name. Preserve names I explicitly said I like in later reorganizations.

Write a short description for each playlist. If supported, upload a playlist-specific cover that remains distinguishable even at a small size. Use folders where they make browsing easier. If I request an order, apply it in my Spotify library and state which view you used to verify it.

## 7. Apply the changes, read them back, and report the result

Within this request, I authorize you to create new private playlists in my account, add the selected tracks, and save the new playlists to my library. Change existing playlists only when I have explicitly asked you to edit that playlist. Do not add tracks to or remove tracks from Liked Songs on your own.

If a Spotify connection is needed, use the official authorization flow. Create the new playlist as private and verify its visibility. If the tool can only create public playlists, ask me first whether an empty draft with a neutral name can be briefly visible to others. If I grant permission, make the draft private and verify it before adding the personal name, cover, and tracks.

When updating a playlist, match the correct playlist using its Spotify link or URI in addition to its name. If the work stopped midway, first read the latest state on Spotify. When I ask you to move a track, verify that the same recording is present in the target playlist before removing it from the source. That way, retrying a move won’t duplicate a playlist or lose a track.

When the work is finished, read back the names, counts, playability, and track order from Spotify. Where possible, check the artwork and folder layout in the library view as well. In a brief report, give me the scope you reviewed, the listening purpose of each playlist, its song count, and its real Spotify link. When reporting counts, distinguish the tracks that came from my likes, those found only in my other playlists, and those not found anywhere in the archive you scanned. Explain why two or three of your selections suit me.

If you cannot read my library, ask for my exported file or the relevant playlist links. If you can read my library but cannot write to Spotify, prepare an importable file containing the recordings you verified. Each row must include the playlist name, order, artist, track, and a real Spotify link or URI. Clearly state which steps were applied and which were only prepared.
